# 管理画面の更新後の再ログインと「実行中」表示

- **更新後の自動ログインは一度きりの引き継ぎ鍵で行う**: 常駐が再起動するとメモリ上のセッションが失われるため。鍵は応答にだけ載せ、状態フォルダーにはハッシュ・ポート・時刻（期限 10 分）だけを置き、新しい版が起動時に必ず消す。トレイの鍵とは別枠にし、互いに無効化しない。鍵が使えないときはトレイから開き直す。
- **「実行中」の記録は保守の契約から切り離す**: 書き込みは best-effort で、失敗しても保守の結果・履歴を変えない。異常終了で残った記録は、PID の生存と開始時刻の照合で表示から除き、次の保守の開始時に掃除する。
- **`GET /activity` は読み取り専用で、無操作の時間を延ばさない**: 開いたままの画面の自動更新が、60 分の自動終了とセッションの失効を妨げないようにする。
