# CHANGELOG の契約

- **編集範囲**: worker が編集してよいのは `Unreleased` 節だけ。
- **未リリースの判定**: 未リリース節とそのリンクラベルの判定は `changelog::is_unreleased_name` / `UNRELEASED_NAMES`（英語を含む 9 言語の固定一覧。見出し名全体の一致で、版付き・部分一致・`未リリース - 1.0.0` は認めない。角括弧なしの英語だけは従来どおり先頭の語で一致する）に集約する。リンク参照定義は、英語の `unreleased` と、編集前の文書に同名の未リリース節の見出しが実在するラベルだけを不変の検査から外し、それ以外は一覧にある名前でも通常のリンクとして検査する。
- **リリース済み節の不変**: `changelog::released_entries_error` が検査する（節はフェンス外の `## ` 行で分け、増えてよい版の節は範囲内のタグに対応するものだけ）。
- **コミット履歴**: 前回の CHANGELOG 変更から今回の push までを、長さ・件数を制限した JSON として**信頼できないデータ**の枠で渡す。
- **版の節への移動**: `on_release = "promote"` は範囲内のタグに対応する節がまだ無いときだけ `Unreleased` を版の節へ移す（冪等）。範囲内のタグの判定は `changelog::range_tags`、綴りの解決は `changelog::lookup_in_rev`（決められないときは違反）に集約する。
- **違反理由**: 見出し文字列を出さず番号で示す（hook の返答に載るため）。
- **worker への指示**: 既存の CHANGELOG への追記には、確かめた変更だけを書き push 自身の CHANGELOG 更新を尊重する指示（`VERIFY_BEHAVIOR_RULE`）を足し、新規作成には足さない。
