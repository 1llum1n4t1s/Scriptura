# 分割先の案内の規則と検査

- 規則: 分割先（`split_dir`）直下の各 `.md` は、その種類の親文書（`AGENTS.md` など）から相対パスで案内する。分割先のファイルを作成・改名・削除したら親文書の案内も同じ保守で直す。worker への指示（`kinds::settings_frame` の `Split directory links`）は分割の有無に関係なく常に入る（AGENTS は「Before changing X, read docs/agents/x.md」の 1 行案内）。
- 検査（`kinds::check_split_links`。`check_documents` から全種類に、権限モードに関係なく）: 許可パスの分割先直下の既存の通常ファイル（リンクは対象外）ごとに、同じ種類の追跡済み文書すべて（`AGENTS.override.md` と、許可パスに無いものを含む。読むだけ）の本文に、そのファイルへの相対パス（親文書のフォルダーからの `../` を含む正しい相対パス。大文字小文字は区別せず、`\` は `/` に揃え、直前の `./` とアンカー `#…` は許す）があるかを確かめる。
- 一致はパス名の途中からでなく、行頭・空白・`(`・`<`・`` ` ``・`[` などの境界の直後から始まるものだけ（`docs/old-design/x.md` は `design/x.md` に一致しない）。
- どの文書にも無いときだけ `Violation::MissingSplitLink`（ソフト違反）。宛先（`path`）は許可パスの中で最も浅い親文書で、`AGENTS.override.md` は宛先にしない（個人用の上書きで、worker に編集させない）。追い修正の文は宛先文書のフォルダーからの相対パス（入れ子なら `../` 付き）で欠けたファイル名を示し、上限・必須見出しと同じ追い修正と警告の経路に乗る。
- 許可パスに同じ種類の親文書が 1 つも無い種類（直せない）と、分割先を持たない種類は検査しない。
